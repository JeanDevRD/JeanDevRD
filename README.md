## 👨‍💻 About Me

I'm a Software Development student at ITLA with a technologist degree in the same field. I like backend work: building APIs, keeping code organized and readable, and working with a team to ship something that actually runs. C# and ASP.NET Core are my home base, and I use them as a reference whenever I pick up a new language.

I did an internship at ITLA developing **RADAR CIUDADANO**, a citizen-feedback platform to help improve public services. I'm now leaning toward DevSecOps and want to grow into CI/CD and secure software practices. Outside of code, I'm into gaming, UFC, and anime.

## 🧱 What I've Built

- **RADAR CIUDADANO:** internship project at ITLA. ASP.NET Core 9 with Onion Architecture, an MVC web app and a separate REST API.
- **MedAnalyzer:** Web API in ASP.NET Core for medical analysis with AI, with JWT authentication, built with a team.
- **CitadoDev:** team project in ASP.NET Core MVC, managed on Azure DevOps.
- **Plant species app:** Android app in Kotlin with Room for local storage.
- **Data structures coursework:** AVL trees, heaps, priority queues, and tries, with Big-O analysis.
